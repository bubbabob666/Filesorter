# Filesorter

Ein einfaches Python-Skript zur automatischen Organisation von Dateien in einem Verzeichnis. Das Tool scannt einen angegebenen Ordner und verschiebt Dateien basierend auf ihrer Dateiendung in entsprechende Unterordner.

## Funktionen
- **Automatisierte Sortierung:** Erkennt Dateiendungen automatisch.
- **Fehlerbehandlung:** Stabiler Betrieb durch `try-except`-Blöcke.
- **Erweiterbar:** Einfache Konfiguration der Dateitypen über ein Dictionary.

## Installation & Nutzung
1. Stelle sicher, dass Python 3 auf deinem System installiert ist.
2. Klone das Repository oder lade die Datei `Filesorter.py` herunter.
3. Führe das Skript über das Terminal aus:
   ```bash
   python file_sorter.py
